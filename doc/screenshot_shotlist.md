# Screenshots to take after heading sentences are implemented

Replace the gray stand-ins in `doc/source/_static/`. Each filename is the one
the Headings page already references.

| File | What to capture |
| --- | --- |
| `screenshot-heading-chapter-menu.png` | **Mark as ...** open on the first sentence of the first chapter, in a prose project or in a verse project's first chapter. The menu shows **Chapter heading**. The Old English on the card is in its real case, not capitals. Do not use a later chapter of a verse project for this shot. |
| `screenshot-heading-section-menu.png` | A prose project. **Mark as ...** open on the second sentence of that chapter's first section, while the first sentence is a chapter heading. The menu shows **Section heading**. A verse project never shows this item. |
| `screenshot-heading-subsection-menu.png` | **Mark as ...** open on a later sentence in the section. The menu shows **Subsection heading**. A verse section can supply this shot. |
| `screenshot-verse-section-menu.png` | The **section dropdown** in the toolbar, not **Mark as ...**. Open it on a verse section in Judith, The Seafarer, or The Battle of Maldon. The list shows a name such as `Lines 101-200`. |
| `screenshot-verse-no-section-heading.png` | **Mark as ...** on the first sentence of a later verse section, such as Verse 101-105. The menu lists **Not Paragraph Start**, **Not Section Start**, and **Chapter Start**. It does not list **Section heading**. |
| `screenshot-heading-cleared-dialog.png` | The dialog after **Not a heading** on a chapter heading whose next sentence was a section heading. The message should name that sentence and `Section N`. Take this in a prose project. |
| `screenshot-heading-refused.png` | The warning when a move would leave a heading in the wrong slot, for example **Add Sentence → Before** on a chapter heading. |
| `screenshot-heading-full-translation.png` | The Full Translation window with a chapter heading in capitals and bold, a section heading in bold, a subsection heading in italics, and one heading that has no Modern English so the right column shows the Old English. The section heading has to come from a prose project. |
| `screenshot-heading-pdf.png` | A PDF page that opens with a later chapter's heading in capitals, Old English on the left and Modern English on the right. Not the first page of the text. In a verse project, name the earlier chapters before this later chapter heading will exist. |

Also retake `screenshot-mark-as-menu.png` if that open menu now lists a heading. The Project Organization page uses it for **Paragraph Start**, **Section Start**, and **Chapter Start**. **Chapter Start** is the split that begins a new chapter. It is separate from **Chapter heading**, which names a chapter that already exists.
