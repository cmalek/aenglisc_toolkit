# Bundled Tectonic Assets

This directory contains the PDF engine payload bundled into release builds.

Expected layout:

- `binaries/macos/arm64/tectonic`
- `binaries/macos/x86_64/tectonic`
- `binaries/windows/x86_64/tectonic.exe`
- `bundle/default/` (offline TeX bundle content)
- `manifest.json` (hashes generated by `scripts/prepare_tectonic_assets.py`)

Use:

1. `python scripts/prepare_tectonic_assets.py ...`
2. `python scripts/verify_tectonic_assets.py`

Build scripts and packaging will fail if verification fails.
